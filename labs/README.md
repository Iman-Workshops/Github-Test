# Workshop Labs

These labs are the learner-facing practice path for the workshop. I wrote them so each step teaches one idea and gives learners a way to check their own work.

Use the labs in order:

1. `01-local-git-lab.md`
2. `02-branch-conflict-lab.md`
3. `03-github-round-trip-lab.md`

## Lab Rules

- Type the commands yourself when possible.
- Run `git status` more often than you think you need to.
- Read the output before moving to the next step.
- Keep the practice folder separate from important work.
- Ask "what changed?" before each commit.

## Recommended Timing

| Lab | Time | Result |
| --- | --- | --- |
| 01 | 35 minutes | A local repo with multiple commits |
| 02 | 45 minutes | A branch merge and one resolved conflict |
| 03 | 30 minutes | A pushed GitHub repo and one pulled remote change |

If time is short, teach Lab 01 fully, then demo the conflict part of Lab 02.
